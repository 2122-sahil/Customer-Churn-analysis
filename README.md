# Customer Churn Analysis

An end-to-end customer churn analysis project using **Python and Power BI** to explore customer behavior, identify patterns associated with churn, and present the findings through an interactive dashboard.

## Objective

The objective of this project is to understand customer churn and identify customer characteristics and service patterns associated with higher observed churn.

## Analysis

- Data understanding and quality checks
- Data cleaning and preprocessing
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Customer segmentation
- Interactive Power BI dashboard

## Key Areas Analyzed

- Contract Type
- Payment Method
- Internet Service
- Technical Support
- Online Security
- Tenure
- Monthly Charges
- Total Charges

## Key Findings

- Overall observed churn rate: **26.7%**
- Month-to-month customers show the highest observed churn rate.
- Electronic-check customers show higher observed churn than other payment-method groups.
- Fiber-optic customers show higher observed churn than DSL and no-internet customers.
- Customers without Technical Support or Online Security show higher observed churn.
- Churn is more concentrated among customers with shorter tenure.
- Churned customers have higher average monthly charges.

> These findings describe relationships observed in the dataset and do not establish causation.
